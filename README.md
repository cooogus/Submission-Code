# Reasoning Path Fingerprints

This repository contains data-cleaning and analysis scripts for studying hidden structure in multi-attempt LLM benchmark results.

The project focuses on two ideas:

1. **Reasoning Path Consistency (RPC)**  
   How similarly a model reasons across multiple attempts on the same question.

2. **Parametric Sampling Fingerprints (PSF)**  
   How model accuracy changes as Pass@k increases from k = 1 to 4.

This repo currently supports cleaning and analyzing benchmark outputs for:

- AGIEval LSAT Analytical Reasoning
- AIME 2025
- GPQA Diamond
- MMMU Accounting
- MMMU Clinical Medicine
- MMMU Finance Merged
